3. LEAVE MODULE - RELIEF ASSIGNEE (new feature)
-------------------------------------------------------------------

3.1 Feature

    When an employee applies for leave, add an optional field letting them
    assign a colleague to relieve/cover for them while they are away.

    Field name   : Relief Employee (or Covering Colleague)
    Required     : Optional
    Input type   : Employee picker (search/select)
    Scope        : Likely same team/department only - to confirm

3.2 Open Questions

4. SELF-SERVICE / ADMIN DASHBOARD SEPARATION
-------------------------------------------------------------------

4.1 Problem

    The HR/admin dashboard currently mixes HR-admin features with employee
    self-service features. This duplicates a separate, dedicated
    self-service dashboard that already exists.

4.2 Required Fix

    Add a two-way mode toggle: "Admin Service" / "Self-Service"

    - Clicking "Admin Service"  -> switches the current user into admin mode
    - Clicking "Self-Service"   -> switches the current user into
                                    self-service mode
    - Behavior is symmetric / reversible both ways

4.3 Scope of Cleanup

    Once the toggle exists:
    - Remove every self-service feature currently duplicated on the
      admin/HR dashboard
    - Admin/HR dashboard shows ONLY admin-related features going forward
    - The existing self-service portal is untouched and continues to own
      employee profile management and all employee-facing features

4.4 Stated Rationale

    Keeps the admin codebase and the self-service codebase cleanly
    separated.

4.5 Open Question

    Is the toggle a global navigation element (visible everywhere, switches
    the whole app's context), or is it scoped to the HR module page only?
    This determines whether it's a layout-level or page-level component.
